# Entry Detail Full Width — Owner-test artifact contract

This document records the distribution evidence boundary for the optional Full Width `gravity_flow.entry_detail` visual variant.

An Owner-test ZIP may be produced only from the final exact PR Head after the structural CSS-only gate, Current / Safe preservation, WU18 browser qualification, Print regressions, WU19, WU21, Registration runtime, production reachability, and the repository release dry-run / exact-ZIP smoke have passed.

The installable ZIP must contain the Full Width production runtime files, including its isolated stylesheet and lifecycle-backed PHP adapters. Development tests, browser fixtures, screenshots, architecture documents, and repository tooling remain excluded by the existing distribution contract.

The ZIP is test evidence only. It does not create a tag, GitHub Release, publication, deployment, or Owner visual acceptance. Final Owner-site acceptance remains a separate runtime decision.
