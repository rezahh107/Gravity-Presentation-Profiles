## 3. `CURRENT_PHASE_SCOPE_FREEZE`

The existing Inbox page is the visual baseline. **Active exactly:** `NATIVE_ROW_DESIGN`, `NATIVE_PAGINATION_PRESENTATION`. **Frozen this phase:** page-level heading, duplicate «کارهای من» headings, refresh button, Search presentation, Settings, Fullscreen and outer page composition. This is reversible by explicit Owner authority, not a permanent architectural ban. Sort/Filter are compatibility preserve-only.

Row direction: **Native Row + Card-Derived Visual Hierarchy**: semantic cue, prominent student name, compact school/grade-group, textual entry-month/status chips if qualified, and native Open/View. Keep a compact row; no Card Mode, card-height rows, heavy shadow, excessive padding, 10+ visible columns or photos. Desktop 1440px; minimal readable RTL fallback at 320–414px. Native pager may receive bounded presentation, while Flow/AG retain current page, page count, page size and lifecycle. Its exact visual method remains a separate design decision.

## 4. Registry vocabulary

`DESIGN_TOOLS` lists only mechanisms a designer can actively use, conditionally explore, or must avoid. `HOST_INVARIANTS` lists operational behavior that can be relied on but never owned or duplicated. `FLOW_VALUE_PATH` verifies ordinary value serialization only; it never proves HTML/SVG rendering. `FLOW_COLUMN_PATH` verifies the named column mechanism. `UNDOCUMENTED_VERSION_BOUND_SEAM` is `gravityflow_js_config_shared → grids[id].grid_options`, JSON only; JS may overwrite keys. `CSS_PAINT` changes appearance; `CSS_GEOMETRY` changes layout/dimensions/overflow and has native pager/focus implications. Selectors are version-bound anchors, not a guaranteed future styling API. `NOT_APPLICABLE` is deliberate. `YES_NOW` describes future decision-material qualification, not execution in this document task.

## 7. Qualification contracts (defined, **not executed**)

- **`Q1_HTML_CELL_VALUE_PATH` — `FIRST`, `YES_NOW`.** One bounded automated probe for ID05/06/10/11: inject controlled benign and unsafe markup through the existing Flow value path; observe render vs escape/strip/transform and unsafe-markup constraint; verify native Open/link, keyboard/focus, raw/data semantics; observe one Live Refresh `update` and one `add` transaction. **Pass** only if bounded rich content survives Flow lifecycle with safe handling and intact raw semantics, link, focus, add/update, without renderer registry or DOM patch loop. **Fail** if required markup is escaped/stripped, unsafe content is not constrained, link/focus/raw semantics break, or takeover/recurring patching is needed. A pass on rendering alone does not prove target schema bindings.
- **`Q2_RTL_NATIVE_BEHAVIOR` — `ACTIVE`, `YES_NOW`.** Observe `.ag-rtl` presence, visual ordering/alignment, native pager direction/order, scroll and keyboard/focus at 1440px and a representative 360px. Do not implement custom paging to pass.
- **`Q3_GEOMETRY_ON_DEMAND` — `ON_DEMAND_IF_DESIGN_DEPENDS_ON_IT`.** Execute only the smallest subtest for the selected ID17–19/25–27/30/40/T54: clean/saved width; maxWidth; flex; row height; min-height CSS; whole-Grid domLayout; empty/overlay; mobile reflow.
